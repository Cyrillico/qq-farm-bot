# qq-farm-bot vs maile456/qq-farm-bot 差异清单

更新时间：2026-02-22
参考版本：`maile456/qq-farm-bot@929a799`

## 已具备能力

- 多账号会话管理（启动/停止/删除）
- Web 控制台登录鉴权（可用环境变量启用）
- QQ 扫码登录与二维码刷新
- 实时日志（SSE）与后端筛选分页查询
- 好友列表与一键操作（含高风险动作开关）
- Bark 可视化配置、分类开关、测试推送、运行时生效
- 等级/经验/金币、升级差值、当前最优/下一级最优作物展示

## 主要差异（你当前项目缺少）

1. 前端技术架构差异
- 对方：Vue 3 + Router + Pinia + Element Plus
- 当前：原生 HTML/JS/CSS + hash 路由
- 影响：复杂页面维护成本更高，但改造成本低、部署简单

2. 页面能力差异
- 对方有：土地详情页（逐块地状态/倒计时）
- 当前缺：土地详情页与土地 API

3. 账号配置细粒度
- 对方有：账号级功能开关（自动偷菜/浇水/任务/出售等）可视化切换
- 当前缺：运行中实时细粒度开关（目前偏启动参数级）

4. 系统管理能力
- 对方有：管理员/普通用户、用户管理页
- 当前缺：多用户 RBAC 与用户管理页面

5. 公告能力
- 对方有：公告/通知对话框
- 当前缺：公告发布与展示链路

6. 数据持久化能力
- 对方有：SQLite（账户、配置、部分状态）
- 当前：以内存 + JSON 设置文件为主

7. 主题能力
- 对方有：深色/浅色主题切换
- 当前缺：主题切换与持久化

## 推荐补齐顺序（按你现有代码最小风险）

1. P1：土地详情 API + 页面
- 新增 `GET /api/lands?accountId=<id>`

2. P1：账号级功能开关（运行中生效）
- 新增账号运行配置结构（自动巡田/好友巡查/任务/出售/最低等级作物/经验优先帮助/放虫放草）
- Web 侧实时下发到子进程（IPC）

3. P2：主题系统
- 增加 `light/dark` 主题切换与本地持久化

4. P2：公告系统
- 先做只读公告（JSON 文件源），再扩展管理端编辑

5. P3：多用户与 RBAC
- 基于当前 auth 扩展角色模型与权限路由

6. P3：数据库持久化
- 将账号配置、历史快照、日志索引迁移到 SQLite
